# Plainfield — consulting website

Editorial landing page for a UAE consulting business.

[Open website preview](https://evgenyponomarevnova.github.io/Plainfield/)

## About

A consulting website presenting business services in the UAE through an editorial layout and animated page sections.

## Status and scope

The repository is a frontend presentation. Descriptions of business services are website content, not features supplied by this code.

## Run locally

Clone the repository and serve its root with a static HTTP server. For example, with Python installed:

```sh
git clone https://github.com/EvgenyPonomarevNova/Plainfield.git
cd Plainfield
python -m http.server 8080
```

Open [localhost:8080](http://localhost:8080). A static server previews HTML/CSS/JavaScript; it does not execute PHP or connect external form services.
